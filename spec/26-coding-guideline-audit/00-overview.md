# Specification: Coding Guideline Gap Audit Reports (Spec 26)

## 1. Overview

This specification folder stores all automated and agentic **Coding Guideline Gap Audit Reports** generated by prompt `01-general-prompts/05-coding-guidelines/03-cg-audit-gap-n-steps.md`.

Every audit executed against the codebase:

1. Compares source files against the master coding guidelines at `.lovable/coding-guidelines/coding-guidelines.md` and `spec/02-coding-guidelines/`.
2. Assigns an algorithmic compliance score from **0 to 100**.
3. Catalogs every single discrepancy drop by drop in the master violation ledger.
4. Enqueues remediation tasks in `.lovable/plans/pending/` and `.lovable/plans/subtasks/`.

## 3. Scoring Criteria (0 to 100)

```text
Score = 100 - (Critical_Count * 10) - (Major_Count * 5) - (Minor_Count * 2)
Score is bounded between 0 and 100: final_score = max(0, min(100, Score))
```

- **Critical (-10 pts):** Swallowed errors, panic + return dual handling, explicit `== true` checks, files > 300 lines, disabled CI/CD.
- **Major (-5 pts):** Functions > 15 lines, nested `if` statements, inverted booleans (`!isSuccess`), magic strings/numbers without enums, missing `*Type` enum suffix.
- **Minor (-2 pts):** Return new lines missing (R13), uppercase acronyms (`ID`/`URL` instead of `Id`/`Url`), missing parameter line breaks (> 3 params / > 100 chars).
